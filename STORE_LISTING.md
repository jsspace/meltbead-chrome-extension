# Chrome Web Store listing draft

**Title:** Meltbead – Web Image to Bead Pattern

**Summary:** Right-click a webpage image to preview a fuse bead grid with real color codes and download a pattern and materials list.

**Description:**

See an image you want to turn into bead art? Right-click it and choose **Create a bead pattern with Meltbead**. The extension opens a private, local preview where you can set the grid width, choose a bead brand and color set, and adjust the color limit. The pattern updates automatically.

- Preview a bead grid from a webpage image or a local PNG, JPG, or WebP.
- Match colors against Perler, Hama, Artkal, Nabbi, and MARD reference sets.
- See bead codes and counts, then export a PNG pattern or CSV materials list.
- Open the full Meltbead website editor when you want to adjust individual beads or print a PDF. This step downloads the source image for you to upload again on the website.

Images are processed on your device and are not uploaded to Meltbead. Chrome asks for site access only when you choose to load an image from that website. Some websites block image downloads; you can save the image and upload it manually instead.

This listing focuses on the Chrome right-click workflow. The website's own pattern-maker page covers the full online editor and printing workflow.
